# MacLean

使用随包发布的 `scripts/maclean.py`，Python ≥3.10，只依赖标准库。运行前阅读 [安装与宿主接入](INSTALL.zh-CN.md)。研究范围和实际验证状态见 [验收记录](ACCEPTANCE.zh-CN.md)，不要把 ready 规则等同于本机版本已验证。

## 工作流程

1. 在目标 Mac 执行 `python3 <技能目录>/scripts/maclean.py capabilities`。核对软件、规则及包摘要。若没有 Mac 执行／文件传输能力，说明具体缺项，不在云 HOME 扫描，不要求或创建 API Key。
2. 执行 `scan`，用户选定的项目使用 `--project /绝对路径`；自定义根用 `--root-map 名称=/绝对路径`，保留项用 `--keep /绝对路径`。`inspect --path /绝对路径` 使用相同规则和受限探针。不要读取会话、凭据、日志或源码正文来判断缓存。
3. 用 `report --record 扫描ID --output /报告目录` 生成 HTML 和 Markdown。解释现在可处理、等待、保留、待调查、空目录和覆盖缺口；部分扫描绝不能称完整。已验证真缓存默认选中，本地下载、编译成本及近期生成不是排除理由。
4. 从用户选择得到仅含目标 ID 的 JSON 数组。使用 `plan --scan 扫描ID --selection /选择.json` 生成封存计划，再 `report` 展示计划的精确作用域、影响及 SHA-256。
5. 调用 `apply --plan 计划ID`，由 Mac 原生对话框取得一次批量批准。让用户亲自确认。AI 不得点击确认、输入确认文字、传入批准字段、调用内部测试授权、修改封存记录或替换批准实现。无批准通道保持预览。
6. 用返回的收据 ID 生成报告。区分 completed、pending、failed、skipped；分别解释目标处理量、剩余清单量和卷空闲变化。pending/failed 需要重新扫描和规划，不能盲目重放不确定操作。

## 规则边界

规则在 `rules/catalog.json`。专用域验证失败不回退，research 只能发现，保护子项不能通过选中父目录绕过。HTML 只能导出选择，不能批准删除。不得自动开启维护、删除 worktree、卸载工具、下载新规则或扩大到系统文件／个人内容。

未支持对象如需研究，查官方写入端与生命周期；在开发环境补齐证据、版本、fixture、原生集成验收后发布新规则。不要临时生成清理脚本或因用户点击确认把研究项变成可删。

## 远程宿主

通过已有 Mac 连接器传输**原始 ZIP 字节或分块 Base64**及发布摘要。使用随包的 `scripts/transport.py` 校验完整包和预期版本，缺块、摘要失败、版本不符必须停止。执行、长任务状态查询、报告读取都经该连接器；不要创建新 MCP 服务。不要把本机 Agent＋连接器 API 测试称为 ChatGPT 网页端完整验收。
